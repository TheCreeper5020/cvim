# TheCreeper5020's Vim
TheCreeper5020's Vim, or cvim for short, is my custom Neovim configuration. It may not have all the features you need and/or may have features you do not like; it is tweaked for MY usage, not yours, but if you want to use it as a base, you can always tweak things.

# Installing
1. Clone this github repository (Backup existing configuration first!)
2. Enjoy! (Note: you may have to install some packages, use your distribution's package manager for that)
