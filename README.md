# TheCreeper5020's Vim
TheCreeper5020's Vim, or cvim for short, is my custom Neovim configuration. It may not have all the features you need and/or may have features you do not like; it is configured for **my** usage, not yours, but if you want to use it as a base, you can always tweak things.

# Installing
1. Make sure you have the following programs:
    * `ripgrep`
    * `fzf`
    * `git`
    * For Arch-based distros: `sudo pacman -S --needed base-devel ripgrep fzf git`
2. **Backup existing configuration** if you don't want to lose it.
3. Clone this github repository using `git clone https://github.com/TheCreeper5020/cvim.git <CONFIG_DIR>` (replace `<CONFIG_DIR>` with the configuration folder's location, such as `~/.config/nvim/` on most Linux distributions)
4. Enjoy! (It may take a minute for plugins to install on first launch, especially blink.cmp)
